A timekeeper for Toastmasters-style meetings, built as an offline-first web app. Times speakers with green, amber and red signals, records results and prepares a Timer's report. Includes agenda import from a photo.

[Source code and documentation](https://github.com/josuekb09/tommy-)

An academic research platform I founded to help students and researchers find scholarly sources, inspect citations and write with traceable evidence. The application source code is private.

[Live product](https://www.useaitocite.com/) · [Public showcase](https://github.com/josuekb09/UseAiToCite-showcase)

### SafeSense

An assistive safety prototype for deaf and hard-of-hearing users, built with React, Express and TensorFlow.js. Detects selected sounds and provides visual alerts, vibration where supported and optional trusted-contact SMS. Experimental prototype, not a certified safety product.

[Source code and documentation](https://github.com/josuekb09/SafeSense)

A church media and communication web app I built for my church, designed to help manage and display service content.
